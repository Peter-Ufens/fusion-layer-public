# LIMITES-GAMMA-GRATUIT.md

**Date observée :** 2026-08-03 (Peter · deck Iris-MCP)  
**Compte :** Gamma **gratuit** (pas Pro)

## Ce qui marche

- Générer ~10 slides par prompt
- Enchaîner plusieurs prompts dans **une** présentation (formule « Ajoute les slides… »)
- Lien partageable `gamma.app/docs/...`

## Friction gratuit (à anticiper)

1. **Ordre des slides** : Gamma peut **déplacer / mélanger** les slides à l’ajout → **réorganiser à la main**.
2. **Ajout parfois ignoré** : risque de créer un 2ᵉ document → **plan B** = fusion manuelle.
3. **Fonctions PRO** (capture paramètres 03/08) :
   - Exiger un **mot de passe** pour consulter
   - **Rendre visible sur internet** (indexation / SEO)
4. **Quota mensuel** : plafond de générations / mois. Si épuisé → **pause** nouveaux decks · reprendre la file (cartographie A-traiter) au reset.

## Règle projets IA-CURSOR

- On **livre** le deck en gratuit (assez pour FT / curieux / vitrine).
- On **n’attend pas** Pro pour clôturer le chantier prompts.
- Si passage Pro plus tard : polish + options partage, **aligné** sur l’état live du projet (pas un deck orphelin).
- Puis **audit** type `D:\Audit-Github\plans\analyses-gamma-*.md` (les decks mai 2026 étaient en **Gamma Pro**).
